## 技术栈
- 纯 Android 原生 API（无第三方依赖）
- Java
- Gradle 8.8 / AGP 8.4.2
- minSdk 23(Android 6) / compileSdk 34(Android 14)

## 使用
1. 安装 APK（开启"允许未知来源"）
2. 打开应用 → 开启无障碍服务
3. 配置替换规则/断句/颜文字
4. 根据自己的喜欢调整设置 → 保存设置
5. 在任意应用的输入框中打字，触发规则自动改写
